# Mobile prototype

`chattyoh_mobile/` preserves the supplied Flutter/WebView shell and its bundled UI preview. `standalone-preview.html` is the supplied mobile HTML preview.

The mobile package is prototype material, not a verified store-ready build. The supplied platform audit states that the Flutter code had not been compiled or run in its audit environment. Follow the mobile project's own setup instructions and validate it with the Flutter toolchain before relying on it.
