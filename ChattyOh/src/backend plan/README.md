# Backend and delivery plan

This folder preserves existing ChattyOh planning artifacts rather than implying that a backend has been implemented.

- `chattyoh-docs/` is the existing documentation pack: product brief, SRS, architecture, security and threat models, OpenAPI contract, test and release plans, traceability tools, and Cursor rules.
- `ChattyOh Inc — Project Documentation Plan.md` defines the document sequence, ownership, and baseline decisions.
- `ChattyOh Inc — Full Platform Audit (Nov 1, 2026) (1).md` records the prototype's tested and code-reviewed gaps.

The detailed plan and security documents are drafts. Hosting, identity, LLM provider, and compliance decisions remain open; the prototype itself has no production backend.
